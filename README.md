# Glub AI

A lightweight, responsive web chat application running directly in the browser with no build steps or heavy dependencies.

**Live Demo:** [https://supaman1.github.io/Glub-ai/](https://supaman1.github.io/Glub-ai/)

---

## Features

- **Instant Browser Access:** Pure HTML5, modern CSS, and JavaScript with zero build configuration required.
- **Dual Environments:** Includes both production and active development/testing interfaces.
- **Hosted on GitHub Pages:** Optimized for static hosting platforms.

## Getting Started

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Supaman1/Glub-ai.git](https://github.com/Supaman1/Glub-ai.git)
   cd Glub-ai
   ```

2. **Open locally:**
   - Double-click `index.html` to open it directly in your browser.
   - Alternatively, spin up a lightweight local server:
     ```bash
     # Using Python
     python3 -m http.server 8000

     # Using Node.js
     npx serve .
     ```
